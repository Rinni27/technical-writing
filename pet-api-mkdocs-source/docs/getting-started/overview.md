# Overview

The **Petstore Pet API** provides a RESTful interface to manage pet records in the store. It supports full CRUD operations, allowing you to create, retrieve, update, and delete pet entries using standard HTTP methods. This guide is designed for both **end customers** exploring the capabilities of the platform and **developers** integrating with it programmatically.

!!! info "Base URL"
    All API requests must be prefixed with the following base URL.

    ```
    https://petstore3.swagger.io/api/v3
    ```

## What you can do

| Method | Capability |
|---|---|
| `GET` | Retrieve pet data |
| `POST` | Create a new pet |
| `PUT` | Update pet info |
| `DELETE` | Remove a pet record |

Continue to [Authentication](authentication.md) to learn how requests are secured.
