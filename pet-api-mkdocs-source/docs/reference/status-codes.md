# HTTP Status Code Reference

| Code | Name | Description |
|---|---|---|
| `200` | OK | Request succeeded. Response body contains the result. |
| `400` | Bad Request | Invalid input. The request syntax is malformed or required fields are missing. |
| `404` | Not Found | The requested resource (pet) does not exist. |
| `405` | Method Not Allowed | HTTP method is not supported for this endpoint. |
