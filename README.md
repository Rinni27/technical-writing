## 📘 *Sample Procedure*
### Procedure on How to Add Contacts on Apple iPhone 7 ?

Add contacts to save details like name, phone number, email address, and more.

***Assumptions***: *Familiar with iPhone 7 functionality, comfortable using ios, and familiar with older iPhones*

To add contacts, perform the following steps:

1. Touch **Phone**.

2. Touch **Contacts**.

3. Touch the + icon.

4. Touch **First Name**.

5. Enter the contact's first name.

6. Touch **Last Name**.

7. Enter the contact's last name.

8. Touch **add phone**.

9. Enter the contact's phone number.
You can also touch the other fields to add email addresses, additional phone numbers, and other details.

10. Touch **Done**.

11. The contact has been saved. 
Touch **Contacts** to return to the contacts list.

12. The new contact appears in the list.

## 🤖 *AI Agent DeckCaster*

- DeckCaster allows you to drop files in following formats: .PDF, .PPTX, .XML, .JSON, .HTML and gives you narrated MP4, which you can push into your GitHub repository.

### Complete MVP
- Perplexity for Deep Research
- Claude for Plan Layout
- Cursor for initial build (Was able to identify MAC issue with Cursor)
- Replit for final build, fixes, post deployment fixes and deployment

### Features
- Sign up and get started. Every User has unique dashboard and documents uploaded will be unique for every user meaning User A won't be able to access the documents of User B
- Renders whiteboard images or handwritten whiteboard notes into narrated MP4
- Compatible with all Operating Systems (Windows, Mac, Linux) and no separate installations for audio or video is required
- Renders your HTML, XML, JSON perfectly into narrated MP4
- Handles the case where the code is badly-written, but does not guarantee the perfect output
- Real time live analytics, users using this agent, and location set to visible only to admin or creator
- Additional security layers
- No modification can be done by users to this agent
- Renders the output directly to your GitHub repository
